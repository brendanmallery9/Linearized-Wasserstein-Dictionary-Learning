# WDL rebuttal GPU workflow

This is a lightweight workflow scaffold, not a copy of historical experiment evidence. Start with [AGENTS.md](AGENTS.md), then read the durable registers below.

- [CONTEXT.md](CONTEXT.md): environment, scope, next actions
- [REVIEWS.md](REVIEWS.md): reviewer concerns (not transferred)
- [EXPERIMENTS.md](EXPERIMENTS.md): new authorized experiment register
- [DECISIONS.md](DECISIONS.md): decisions and rationale
- [RESEARCH_LOG.md](RESEARCH_LOG.md): append-only activity record
- [RESULTS_SUMMARY.md](RESULTS_SUMMARY.md): inspected results only
- [templates/](templates/): experiment, task, and report templates
- [reports/](reports/): task handoffs
- [environment/](environment/): setup provenance

Code originates from GitHub main. Workflow scaffold lives on `codex/rebuttal-gpu`. Historical data, reports, reviews and local code modifications remain on the primary Mac checkout. Never infer that an empty register means prior research did not happen.
